## 🚀 How to Run the React Project

### 1. Clone the repository

```bash
git clone https://github.com/Prinit123/Web-Development.git
```

### 2. Open the project folder

```bash
cd Web-Development/re
```

### 3. Install dependencies

Make sure [Node.js](https://nodejs.org/) is installed, then run:

```bash
npm install
```

### 4. Start the development server

```bash
npm run
```

Check the available scripts printed by that command. If the project has a `start` script, run `npm start`. If it has a `dev` script, run `npm run dev`.

Open the local URL displayed in your terminal.
